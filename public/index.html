    Session Visibility & Rule Controls

    Session: SES-XXXXX

    Blind Count (Counters Hidden) STANDARD AUDIT

    Counters cannot see book stock or variances. They must physically inspect shelves. Prevents guessing or copying ERP quantities.

    Executives & Managers can view system stock and variances to guide recounts.
    Strict Blind (Hide from Executives & Counters) STRICT AUDIT · MANAGER ONLY

    Manager hides system qty from executives as well. Neither floor counters nor executives can see expected stock or live variance calculations.

    Only Central Manager / Admin can view book stock. Eliminates executive bias & collusion.
    Open Count (Visible to Everyone) TRANSPARENT COUNT

    All operators, executives, and managers see expected system quantities and live +/- variances directly on screen.
